# Windows Server 2022 Labs

## Overview

This repository documents my hands-on labs and practical learning using Windows Server 2022. It focuses on Windows server administration, Active Directory, user and group management, security configuration, and Windows event logging.

The goal is to develop practical Windows infrastructure and security monitoring skills relevant to enterprise IT environments and Security Operations Center (SOC) operations.

## Objectives

- Install and configure Windows Server 2022.
- Configure Active Directory Domain Services (AD DS).
- Create and manage domain users, groups, and organizational units.
- Configure Group Policy Objects (GPOs).
- Configure DNS and DHCP services.
- Manage permissions and access control.
- Configure Windows Firewall and security policies.
- Monitor Windows Event Viewer logs.
- Generate and investigate security events.
- Understand Windows authentication and domain security.

## Tools and Technologies

- **Windows Server 2022** — Server operating system.
- **Active Directory Domain Services (AD DS)** — Centralized identity and access management.
- **Group Policy** — Centralized configuration and security policy management.
- **DNS and DHCP** — Network name resolution and IP address assignment.
- **Windows Event Viewer** — System and security log analysis.
- **Virtualization Software** — Isolated lab environment.
